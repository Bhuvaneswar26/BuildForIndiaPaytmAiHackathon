# Knowledge base

Put GST explainer text here as `.md` files. The advisor indexes `##` sections at startup.

To use real PDFs at the hackathon:

1. Copy PDFs into `pdfs/`
2. Paste or extract text into a new `.md` file (same folder as this README)
3. Restart the advisor process

Keep numbers aligned with `skills/gst-explainer-consistency/SKILL.md` so alerts and the chatbot do not contradict each other.
